
# KHALID DEAL HUNTER — نسخة البداية

## تنبيه مهم قبل التشغيل
هذه نسخة تأسيسية وليست ضماناً أن المتاجر الأربعة ستُرجع المنتجات مباشرة.
المتاجر تغيّر صفحات البحث، وبعضها يستخدم JavaScript أو يقيّد الطلبات الآلية.
المحلّل الحالي يقرأ بيانات المنتجات المنظمة (JSON-LD) عندما تكون موجودة.
إذا لم يُرجع متجر منتجات، نحتاج تكييف محلّل ذلك المتجر بعد فحص صفحته الفعلية.

## 1) إنشاء بوت Telegram
1. افتح Telegram وابحث عن `@BotFather`.
2. أرسل `/newbot` واتبع التعليمات.
3. انسخ Token واحتفظ به سرياً.
4. افتح البوت الجديد وأرسل له `/start`.
5. للحصول على Chat ID، افتح في المتصفح:
   `https://api.telegram.org/botYOUR_TOKEN/getUpdates`
   وابحث عن `chat.id` في النتيجة.

## 2) رفع المشروع إلى GitHub
1. أنشئ مستودعاً باسم `KHALID-DEAL-HUNTER`.
2. ارفع جميع الملفات كما هي.
3. من Settings > Secrets and variables > Actions > New repository secret:
   - الاسم `TG_TOKEN` والقيمة Token.
   - الاسم `TG_CHAT` والقيمة Chat ID.
4. من Actions فعّل Workflows إذا طُلب ذلك.
5. شغّل `Khalid Deal Hunter` يدوياً أول مرة.

## 3) التشغيل المجدول
الملف `hunter.yml` مضبوط على كل 30 دقيقة.
GitHub Actions ليس خادماً دائماً؛ هذا تشغيل دوري وليس عملية تعمل طوال الوقت.
قد تتأخر المهام المجدولة، وحدود الاستخدام تعتمد على نوع المستودع والخطة.

## 4) سجل الأسعار
يُحفظ في `data/deals.db`.
لا يرسل البوت تنبيهاً موثوقاً عند أول مشاهدة؛ يحتاج إلى 3 قراءات سابقة على الأقل.
يقارن السعر الحالي بوسيط آخر 12 قراءة، ويرسل عند انخفاض 25% أو أكثر.
هذه المقارنة تصبح أفضل كلما طال تشغيله.

## 5) ما الذي يجب تطويره بعد أول تشغيل؟
- اختبار كل متجر على حدة والتأكد من عدد المنتجات المستخرجة.
- إنشاء محلّل خاص للمتاجر التي لا تعرض JSON-LD في صفحة البحث.
- إضافة تحقق من البائع والتوفر وسعر الشحن.
- تحسين منع تكرار التنبيهات.
- إضافة أزرار 👍 / 👎 / ⭐ لتعلم تفضيلات خالد.
- إضافة سجل لآخر وقت فحص لكل متجر وقسم.

## 6) ملاحظات التكلفة والخصوصية
- Python وSQLite وTelegram Bot API لا تحتاج اشتراكاً مدفوعاً لهذا الاستخدام.
- GitHub Actions مجاني ضمن حدود وشروط الخطة.
- لا تضع Telegram Token داخل الكود أو ملفات GitHub؛ استخدم Secrets.
- لا تحاول تجاوز CAPTCHA أو أنظمة الحماية أو حدود المواقع.
- احترم شروط الاستخدام وسياسات المواقع.
